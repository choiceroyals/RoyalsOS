# Installation
1. Stop the current server with Ctrl+C.
2. Back up the current `royalos-app` folder.
3. Extract this package to a new empty location.
4. Copy your private `.env.local` from the backup.
5. Copy any logo/avatar files added after the source ZIP was created.
6. Run `npm install`.
7. Run `npm run dev`.
8. Open Settings to access System Care.

Do not copy `.next` or `node_modules` from the old project.
