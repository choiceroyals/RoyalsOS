CLEAN INSTALLATION

1. Stop the current RoyalOS server with Ctrl+C.
2. Back up the current working royalos-app folder.
3. Extract this ZIP into a NEW EMPTY folder named royalos-app.
4. Copy your private .env.local from the backup into the new folder.
   Never upload, share, or commit .env.local.
5. Copy any local avatar images that are not already in the ZIP.
6. Open Command Prompt or PowerShell in the new royalos-app folder.
7. Run:

   npm install
   npm run dev

8. Open http://localhost:3000

ORION

Open Orion Developer Workbench. The three areas are:
- Inspect · Search · Plan
- Code Proposal
- Execute · Validate · History

Orion requires exact CEO approval before changing files. Review every affected file and type APPROVE only when the proposal is correct. Use ROLLBACK to restore a completed transaction.
